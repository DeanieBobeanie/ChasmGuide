First public beta of the standalone Chasm Guide add-on for WoW Forever 1.60.1, interface 16001.

- Dungeon quest overview, faction filters, details and step-by-step routes.
- City of Dalaran routes for both factions, Horde key preparation and the Alliance follow-up.
- Past Due in the Alliance Scarlet Monastery checklist.
- Saved-progress migration for updated routes, with optional navigation and automation off by default.
- Credit to [Hacker--x](https://github.com/Hacker--x) for contributing an update.

Download the ChasmGuide ZIP below, extract its ChasmGuide folder into Interface/AddOns, then fully restart WoW. Type `/cguide` to open it. Keep WTF when updating. This release contains no RestedXP or Journey modules.

Offline regression and Lua 5.1 checks cover route logic, UI handlers and 672 saved-progress migration cases. Live checks of every dungeon remain pending. Five future dungeon entries are planning references without verified playable routes. See the README for limits and source credits.
