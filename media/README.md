# Screenshot

`in-game.jpg` is an unedited game screenshot captured on 21 October 2026 in Bloodhoof Village on the WoW Forever client. It shows the Horde Ragefire Chasm quest overview.

The installed Lua files matched the v1.3.0-beta.1 release after normalizing line endings and the UTF-8 BOM. The installed TOC labels this build 1.3.0. The screenshot session did not separately query the client build number.

The Combat Log tab was selected to keep conversations out of the image. The Chasm Guide window was centered through its built-in command. Other visible panels belong to the game and other installed add-ons.
